# ST7567 programming summary

Source: Sitronix, *ST7567 65 x 132 Dot Matrix LCD Controller/Driver*, Ver 1.5, 2010/08/06, 49 pages (`ST7567.pdf`).
This is the programming view of the datasheet: interfaces, RAM layout, instruction set, orientation bits, LCD power
circuit and sequences. The ST7567 is command compatible with the ST7565R and the UC1701x and is driven by the vic head
`src/head/ST7565.h` with `Controller = ST7565_ST7567`. The head, the comparison of the three chips and the ST7565R
details are in `ST7565.md`, the UC1701x in `UC1701.md`. Section 8 lists the ST7567 specific points of the review.
Page numbers refer to `ST7567.pdf`.

## 1 Overview

| Item | Value |
|---|---|
| Panel | 132 segments (SEG0..SEG131) x 64 commons (COM0..COM63) + icon common COMS (COMS1 and COMS2 carry the same signal) |
| RAM | 65 x 132 bit = 8580 bit, 8 pages of 8 lines + page 8 with 1 line (icon) |
| Duty | pins SEL2, SEL1: LL 1/65 (bias 1/9 or 1/7), LH 1/49 (1/8 or 1/6), HL 1/33 (1/6 or 1/5), HH 1/55 (1/8 or 1/6) |
| Supplies | VDD1 1.8 .. 3.3 V digital (DC table: 1.7 .. 3.3 V since V1.3), VDD2 2.4 .. 3.3 V analog, VDD3 2.4 .. 3.3 V reference |
| LCD voltage | built-in booster 4x / 5x with on-chip capacitors, regulator with 8 ratios x 64 EV steps (-0.05 %/C), follower; generates V0 / XV0 (COM, positive / negative frame), VG (SEG) and VM (COM non-select) |
| External parts | C1 0.1 .. 1.0 uF / 6 V on VG, C2 0.1 .. 1.0 uF / 16 V between V0 and XV0, R1 reserved (not fitted) |
| Interfaces | PSB = H: 8 bit parallel, C86 = H 6800, C86 = L 8080; PSB = L: 4-line SPI, write only |
| Oscillator | built in, no clock output, frame frequency 70 / 75 / 80 Hz at 1/65 duty |
| Not present (vs ST7565R) | static indicator, master / slave, external clock, external V0 resistors, high power mode pin, 1/53 duty, busy flag |

State after RSTB (p. 20): display off (SEG / COM at VSS), normal display, all pixels on off, MX = 0, serial counter
cleared, bias BS = 0, booster BL = 0 (4x), power save off, power control off (VB = VR = VF = 0), read-modify-write off,
start line 0, column 0, page 0, MY = 0, regulation ratio RR = 4 (5.0), EV = 20h (32), test mode off. RAM content is
undefined after power on, the datasheet recommends to initialise the whole RAM before display on.

## 2 Interfaces

| Pin | Function |
|---|---|
| CSB | chip select, low active; high: D[7:0] high impedance, A0 / ERD / RWR ignored, SPI shift register and 3 bit counter reset |
| RSTB | hardware reset, low active; the initialisation by RSTB is essential before operation |
| A0 | H: display data, L: instruction / status |
| RWR | 6800: R/W (H read, L write); 8080: /WR (data latched on the rising edge); fix to H in SPI mode |
| ERD | 6800: E (write data latched on the falling edge of E, read data driven while E = H); 8080: /RD (low active); fix to H in SPI mode |
| D[7:0] | data bus; SPI: D7 = SDA, D6 = SCLK, D5..D0 to H |
| PSB, C86 | interface selection (table below) |
| SEL2, SEL1 | duty and bias range |
| VDDH, VSSL | logic 1 / 0 levels for the option pins |

| PSB | C86 | Interface |
|---|---|---|
| H | H | 6800 parallel |
| H | L | 8080 parallel |
| L | x | 4-line SPI |

| A0 | 6800 E, R/W | 8080 /RD, /WR | Function |
|---|---|---|---|
| H | H, H | L, H | display data read |
| H | H, L | H, L | display data write |
| L | H, H | L, H | status read |
| L | H, L | H, L | instruction write |

After VDD1 is on no interface pin may float (an MPU that tri-states its pins in sleep or reset can latch garbage).

4-line SPI (p. 13): SDA is latched on the rising SCLK edge, MSB first; after the 8th clock the byte is processed and
A0, latched at the 8th clock, selects display data (H) or instruction (L). No read. The column address increments
after every RAM byte.

Reads (parallel only): the first read after setting the address returns the bus latch (dummy read), valid data
follows from the second read on. Status byte (A0 = 0, read): `0 MX D RST 0 0 0 0`; MX = 0 normal SEG direction,
D = 0 display on, 1 display off, RST = 1 hardware or software reset in progress. There is no busy flag; instructions
execute within the bus cycle.

address and data hold times and the 2.8 V (instead of 2.7 V) column.

## 3 Display data RAM

The RAM has X = 0 .. 131 (column) and Y = 0 .. 8 (page) (p. 15, 16). A byte holds 8 vertical pixels, D0 is the top
line of the page, 1 = pixel on. Page 8 is the icon page, only D0 is valid; COMS is always the last common, the icons
never scroll.

- Page address: B0h | Y (0 .. 8), only changed by the page instruction, must be set before RAM access.
- Column address: 10h | X[7:4], 00h | X[3:0]. The column increments (+1) after every RAM read or write. The text
  says this "stops at the end of each page (83h)" (p. 16, 23) but the write data description on p. 23 says the
  column wraps to 0 after the last column; the page address never changes automatically in either reading.
- MX (A0h / A1h) inverts the column to SEG mapping (MX = 0: column 0 on SEG0, MX = 1: column 131 on SEG0); the RAM
  has to be rewritten after changing MX. MY (C0h / C8h) inverts the COM order.
- Start line (40h | S, 0 .. 63) selects the RAM line shown on COM0; repeated setting scrolls without rewriting the
  RAM (p. 18).
- Read-modify-write (E0h .. EEh): reads do not increment the column, writes do; EEh restores the column. Other
  instructions can be used inside the mode.
- Inverse, display off and all pixels on change only the display latch.

## 5 Orientation

The orientation bits are the same as on the ST7565R (see `ST7565.md` section 5): MX = A0h / A1h mirrors horizontally,
MY = C0h / C8h vertically, no 90 degree rotation. With A1h a 128 pixel panel on SEG0..SEG127 starts at RAM column 4.
After changing MX the RAM must be rewritten. The vic head keeps A0h / C0h and does all orientations in software.

## 6 Power, reset and initialisation

### 6.1 Reset

RSTB resets everything listed in section 1; while RSTB is low only the status read is accepted. The RESET
instruction (E2h) resets only the read-modify-write mode, start line, column, page, MY, regulation ratio (4), EV
(20h) and the test mode; display on/off, inverse, all pixel on, MX, serial counter, bias, booster level, power save
and power control are not reset by E2h and it cannot initialise the power circuit (p. 20, 25). A hardware reset is
needed after power on once the supplies are stable.

### 6.2 LCD power circuit

V0 (p. 26): `V0 = RR x (1 - (63 - EV) / 162) x 2.1 V = RR x (99 + EV) / 162 x 2.1 V`

| RR2..RR0 | 000 | 001 | 010 | 011 | 100 | 101 | 110 | 111 |
|---|---|---|---|---|---|---|---|---|
| RR | 3.0 | 3.5 | 4.0 | 4.5 | 5.0 | 5.5 | 6.0 | 6.5 |
| V0 at EV = 0 / 32 / 63 | 3.85 / 5.09 / 6.30 | 4.49 / 5.94 / 7.35 | 5.13 / 6.79 / 8.40 | 5.78 / 7.64 / 9.45 | 6.42 / 8.49 / 10.50 | 7.06 / 9.34 / 11.55 | 7.70 / 10.19 / 12.60 | 8.34 / 11.04 / 13.65 |

(V0 values calculated from the formula.) The datasheet recommends an EV near the centre (1Fh) for easy contrast
adjustment; the reachable V0 depends on VDD2, the booster level and the panel load.

Bias levels (1/65 duty, 1/9 bias, p. 24): VG = 2/9 x V0, VM = 1/9 x V0; ranges 1.24 V <= VG < VDD2 and 0.62 V <=
VM < VDD2 (p. 24; the pin description and the application notes give 1.6 V <= VG < VDD2 and 0.8 V <= VM < VDD2).
Required order V0 >= VDD2 > VG > VM > VSS >= XV0.

Booster (p. 28, 46): the capacitors are on chip, the level is set by F8h only (BL = 0 4x, BL = 1 5x). Application
voltage guide (VDD = 2.8 V, 1.4 inch panel, 25 C, all with 5x):

| Duty | Vop for the high bias | Vop for the low bias |
|---|---|---|
| 1/65 | 8.5 .. 9.5 V (1/9) | 6.5 .. 7.5 V (1/7) |
| 1/55, 1/49 | 7.5 .. 8.5 V (1/8) | 5.5 .. 6.5 V (1/6) |
| 1/33 | 5.5 .. 6.5 V (1/6) | 4.5 .. 5.5 V (1/5) |

Booster limits with booster stage BL (4 or 5), efficiency BE (80 % for 1.4 inch, 76 % up to 1.8 inch) and bias 1/N:
`VDD2 x BL x BE >= V0` and `Vop <= VDD2 x (BL - 1) x BE x N / (N - 2)`. Example: VDD2 = 2.8 V, 1/9 bias gives a Vop
limit of 8.6 V with 4x and 11.5 V with 5x. VG should be 0.5 .. 0.8 V below VDD2.

### 6.3 Initialisation (p. 29)

1. Power on, wait until the later of VDD1 and VDD2 reaches 90 % (> 1 ms, system dependent). VDD1 and VDD2 / VDD3 may
   come up in any order (tON-V2 >= 0).
2. RSTB low (> 5 us), RSTB high, wait > 5 us for the reset to finish. RSTB may be applied any time after the supply
   is stable, 0 .. 30 ms recommended to avoid an abnormal display; a reset that happened while VDD1 was unstable has
   to be repeated.
3. Bias select (A2h / A3h), SEG direction (A0h / A1h), COM direction (C0h / C8h).
4. Regulation ratio (20h .. 27h), set EV (81h, xx), set booster if 5x is needed (F8h, 01h).
5. Power control (2Fh).
6. Initialise the RAM (pages 0 .. 8), display on (AFh).

Steps 2 .. 5 should complete within 5 ms (panel and capacitor dependent). The datasheet recommends a periodic refresh
of the settings.

### 6.4 Power save and power off

Power save (p. 28, 31): AEh then A5h. The oscillator, the power circuits and the LCD drivers stop, SEG / COM are at
VSS, RAM and registers (except D and AP) are kept. Exit: A4h then AFh; the internal power restarts in sequence, the
stable time depends on the panel load. Typical power down current 8 uA (16 uA max).

Power off (p. 32): either power save (AEh, A5h) or RSTB low (> tRW) then high, wait 250 ms (tPOFF, internal
discharge), then switch off VDD1..VDD3. VDD1 should not go off before VDD2 / VDD3 (tV2OFF >= 0), otherwise the
discharge may stop and charge reaches the panel; the VDD2 / VDD3 fall time should be 20 ms .. 0.2 s.

## 8 The vic head `src/head/ST7565.h`

The ST7567 is driven by `vic::head::ST7565<ST7565_ST7567, ...>`; template parameters, framebuffer layout, `present()`
and the display control functions are described in `ST7565.md` section 8. For `ST7565_ST7567` the init sequence is
`E2h, A2h / A3h, A0h, C0h, 40h, 2Ch, 2Eh, 2Fh (50 / 50 / 10 ms), 20h | ratio, 81h volume, A6h, A4h, AFh`, i.e. the
same as for the ST7565R without the booster ratio command.
