# PCD8544 programming summary

Source: Philips Semiconductors *PCD8544 48 x 84 pixels matrix LCD controller/driver*, 1999 Apr 12
(`PCD8544.pdf`), the controller of the Nokia 5110 / 3310 displays. The last section describes the vic head
`src/head/PCD8544.h`.

## 1 Overview

| Item | Value |
|---|---|
| Panel | 84 columns x 48 rows, 1/48 mux |
| RAM | 84 x 48 bit = 504 byte in 6 banks of 8 rows |
| Supplies | VDD 2.7 .. 3.3 V, internal LCD voltage generator (Vop up to 8.5 V), temperature compensation |
| Interface | serial (SCE, D/C, SDIN, SCLK), MSB first, up to 4 Mbit/s, write only |
| Reset | RES low within 100 ms after power on; after reset: power down, horizontal addressing, display blank, Vop = 0 |

## 2 Interface

Serial bus: `SCE` (chip select, low active), `D/C` (0 command, 1 data), `SDIN`, `SCLK` (data latched on the
rising edge). Bytes are 8 bit, MSB first; the controller never drives the bus.

## 3 RAM and addressing

The RAM is 6 banks (Y = 0 .. 5) of 84 bytes (X = 0 .. 83); a byte holds 8 vertical pixels, bit 0 = top row of
the bank, 1 = pixel on. Addressing modes (function set bit V): horizontal addressing (V = 0): X increments
after each byte, after X = 83 X = 0 and Y increments; vertical addressing (V = 1): Y increments first. A whole
frame in horizontal mode is 504 bytes from (X = 0, Y = 0).

## 4 Instruction set

| Instruction | H | Code | Function |
|---|---|---|---|
| NOP | 0/1 | `0000 0000` | |
| Function set | 0/1 | `0010 0 PD V H` | PD = 1 power down, V = 1 vertical addressing, H = 1 extended instruction set |
| Write data | 0/1 | D/C = 1, data | write a RAM byte at the current address |
| Display control | 0 | `0000 1 D 0 E` | DE = 00 blank, 10 normal (0Ch), 01 all segments on (09h), 11 inverse (0Dh) |
| Set Y address | 0 | `0100 0 Y2 Y1 Y0` | bank 0 .. 5 |
| Set X address | 0 | `1 X6 .. X0` | column 0 .. 83 |
| Temperature control | 1 | `0000 01 TC1 TC0` | VLCD temperature coefficient 0 .. 3 |
| Bias system | 1 | `0001 0 BS2 BS1 BS0` | mux rate: 0 = 1:100, 1 = 1:80, 2 = 1:65, 3 = 1:48 (datasheet), 4 = 1:40 / 1:34, 5 = 1:24, 6 = 1:18 / 1:16, 7 = 1:10 / 1:9 / 1:8 (the reference drivers use 4 for the 5110 modules) |
| Set Vop | 1 | `1 Vop[6:0]` | LCD voltage VLCD = 3.06 V + Vop x 0.06 V (0 = generator off), 0x30 .. 0x40 typical, max 8.5 V |

A typical init is `21h, 80h | Vop, 04h, 10h | bias, 20h, 0Ch`, then address 40h, 80h and the frame.

## 5 The vic head `src/head/PCD8544.h`

```cpp
vic::head::PCD8544<Screen_Size_X = 84, Screen_Size_Y = 48,   // logical size, 48 x 84 for orientation_90 / 270
                   Orientation = drv::orientation_0,          // done in software
                   Vop = 0x38, Bias = 4>
PCD8544(io::handle_type device);
```

- io layer: `io::write()` option 0 = command, 1 = data (the D/C line), SPI mode 0.
- init: 21h, 80h | Vop, 04h, 10h | Bias, 20h, 0Ch, clear, present. `shutdown()` = 08h (blank), 24h (power down).
- Framebuffer: 504 bytes bank organised (bit 0 = top row) in physical orientation, `present()` sends 40h, 80h and
  the 504 bytes in one block (horizontal addressing).
- `display_enable()` = 0Ch / 08h, `display_contrast()` = 21h, 80h | level / 2, 20h, `display_inverse()` = 0Dh / 0Ch.
