# JD9853 programming summary

Source: Jadard *JD9853 240RGB x 320 dot, 262K color, with internal GRAM, a-Si TFT LCD Single Chip Driver*,
Preliminary V0.00 (`JD9853.pdf`). The JD9853 drives the 1.47" 172 x 320 and 2" 240 x 320 modules (Waveshare
ESP32-S3-LCD-1.47 and others). It implements the MIPI DCS user command set, so it is driven by the generic
head `src/head/MIPI_DCS.h` (`MIPI_DCS_JD9853`); the common parts of that command set are in `MIPI_DCS.md`,
this file holds what is specific to the JD9853.

## 1 Overview

| Item | Value |
|---|---|
| Panel | 240 RGB x 320, 720 source and 320 gate channels |
| GRAM | 240 x 320 x 18 bit = 172,800 byte |
| Supplies | IOVCC 1.65 .. 3.3 V, VCI 2.6 .. 3.3 V, internal DC/DC for the panel voltages |
| Interfaces (IM[3:0]) | 8080 parallel 8 / 9 / 16 / 18 bit, 3 line 9 bit SPI (I and II), 4 line 8 bit SPI (I and II), 2 lane SPI, QSPI, RGB (DPI) 16 / 18 bit |
| Colors | 262k (18 bit) in the GRAM, 12 / 16 / 18 bit per pixel on the MCU interface, 16 bit RGB565 on SPI |
| OTP | the vendor register settings are stored in the OTP, the host does not need to send them |
| Extras | partial area, vertical scrolling, tearing effect line, idle mode, 2 lane / quad SPI data transmission |

## 2 Interfaces

4 line SPI: `CSX`, `D/CX` (0 command, 1 parameter / data), `SCL`, `SDA`, MSB first, data latched on the
rising edge of SCL. 3 line SPI: 9 bit frames with the D/CX bit first. The serial interface II variants
have a separate `SDO` for reads, interface I reads on `SDA`. The 8080 bus uses `D/CX`, `WRX`, `RDX` with the
pixel formats of section 3. Reads on SPI return a dummy byte / clock before the first data byte.

The SPI interface runs the 16 bit RGB565 format (COLMOD 55h), unlike the ILI9488.

## 3 Pixel formats (3Ah)

| DBI[2:0] (MCU) / DPI[2:0] (RGB) | Format |
|---|---|
| 011 | 12 bit per pixel (RGB444) |
| 101 | 16 bit per pixel (RGB565) |
| 110 | 18 bit per pixel (RGB666) |

Reset value 66h (18 bit on both interfaces).

## 4 Commands

The standard DCS commands of the JD9853 (parameters in brackets):

| Hex | Name | Function |
|---|---|---|
| 00 | NOP | no operation, terminates a memory read / write |
| 01 | SWRESET | software reset, wait 5 ms (120 ms before SLPOUT) |
| 04 | RDDID | read ID: dummy, 98h, 51h, 01h |
| 06 / 07 / 08 | RDRED / RDGREEN / RDBLUE | read the color of the first pixel |
| 09 | RDDST | read display status (4 bytes: MADCTL bits, pixel format, inversion, display on ...) |
| 0A .. 0F | RDDPM, RDDMADCTL, RDDCOLMOD, RDDIM, RDDSM, RDDSDR | read power mode, MADCTL, pixel format, image mode, signal mode, self diagnostic |
| 10 / 11 | SLPIN / SLPOUT | sleep in / out, 120 ms after SLPOUT before the next sleep command |
| 12 / 13 | PTLON / NORON | partial mode on / normal mode on |
| 20 / 21 | INVOFF / INVON | display inversion |
| 28 / 29 | DISPOFF / DISPON | display off / on |
| 2A | CASET | column start / end (SC[15:0], EC[15:0]) |
| 2B | PASET | page (row) start / end (SP[15:0], EP[15:0]) |
| 2C | RAMWR | memory write from (SC, SP), pointer wrap inside the window |
| 2E | RAMRD | memory read (dummy byte first on SPI) |
| 30 | PLTAR | partial area (start row, end row) |
| 33 | VSCRDEF | vertical scrolling definition (TFA, VSA, BFA), TFA + VSA + BFA must be 320 |
| 34 / 35 | TEOFF / TEON | tearing effect line off / on (35h parameter: 0 V blank only, 1 V and H blank) |
| 36 | MADCTL | MY (B7), MX (B6), MV (B5), ML (B4), BGR (B3), MH (B2), same meaning as on the other DCS controllers |
| 37 | VSCRSADD | vertical scroll start address |
| 38 / 39 | IDMOFF / IDMON | idle mode (8 colors) off / on |
| 3A | COLMOD | pixel format, see section 3 |
| 3C / 3E | RAMWRC / RAMRDC | memory write / read continue |
| 44 | TESCAN | tearing effect scan line |
| D7 | | interface control, 20h selects the 2 lane SPI data transmission |

The user command section (vendor registers for power, gamma and timing) is empty in this preliminary
revision; the reference driver of the 1.47" module writes vendor registers DFh (password), B2h, B7h, BBh,
C0h .. C8h, D0h, D7h, DEh (register page), E5h, E6h, which the head does not need because the module's OTP
holds them.

## 5 Power on / off and sleep

Power on (datasheet 8.7): IOVCC then VCI within tPWON = 5 ms, reset low >= 10 us, wait >= 10 ms after the
reset (5 ms after a software reset), then either the initial settings followed by SLPOUT (page 0 11h) and
DISPON (29h) or, with the settings in the OTP, SLPOUT and DISPON only; 120 ms after SLPOUT before DISPON.
Power off: DISPOFF, SLPIN, then VCI and IOVCC off. Sleep mode keeps the GRAM.

## 6 Panel offsets and orientation

The 1.47" 172 x 320 module is centred on the 240 GRAM columns: CASET 22h .. CDh, i.e. `Offset_X = 34`
for `orientation_0` / `orientation_0m`; with MX set (`orientation_180`, `orientation_180m`) the offset is
also 34 (240 - 172 - 34), with MV set the offset moves to the rows (`Offset_Y = 34`). The 2" 240 x 320
module needs no offset. The reference code sends MADCTL 00h and no inversion, so the modules match the
datasheet default (`orientation_0`, `RGB_to_BGR = false`, `Invert = false`).

## 7 The vic head

```cpp
// 1.47" 172 x 320 module, portrait
vic::head::MIPI_DCS<vic::head::MIPI_DCS_JD9853, 172, 320, vic::drv::orientation_0, false, false, false, 34, 0> tft(handle);
// 2" 240 x 320 module, landscape
vic::head::MIPI_DCS<vic::head::MIPI_DCS_JD9853, 320, 240, vic::drv::orientation_90> tft2(handle);
```

- init: SWRESET (5 ms), SLPOUT (120 ms), NORON, DISPON (20 ms), then MADCTL from the orientation, COLMOD 55h,
  INVOFF and a clear screen. Everything else is in `MIPI_DCS.md`.
- Not covered: the 2 lane SPI / QSPI data transmission (D7h), the RGB interface, partial / scroll / idle
  modes, the tearing effect line, the vendor registers.
