# ST7565 / ST7567 / UC1701 programming summary

Sources: Sitronix *ST7565R 65 x 132 Dot Matrix LCD Controller/Driver* Ver 1.5 (`ST7565.pdf`), Sitronix
*ST7567 65 x 132 Dot Matrix LCD Controller/Driver* (`ST7567.pdf`), UltraChip *UC1701x 65x132 STN
Controller-Driver* (`UC1701.pdf`). The three controllers are command compatible and drive the common 128 x 64
COG LCD modules (ERC12864, DOGM128, Nokia 1202 style ...). The last section describes the vic head
`src/head/ST7565.h`.

## 1 Overview

| Item | Value |
|---|---|
| Panel | up to 132 segments x 65 commons (64 rows + 1 icon row), 128 x 64 modules use 128 of the 132 columns |
| RAM | 65 x 132 bit in 9 pages (page 8 = icon row) |
| Supplies | VDD 1.8 .. 3.3 V (ST7565), 2.4 .. 3.3 V (ST7567), 2.5 .. 3.6 V (UC1701); internal booster (2x .. 6x) and regulator for the LCD voltage V0 (up to 12 .. 13 V) |
| Interfaces | 8 bit 8080 / 6800 parallel, 4 wire SPI (CS, A0, SCL, SI), 3 wire SPI (UC1701), write only on SPI |
| Reset | RES# pin or software reset E2h; the ST7567 needs a hardware reset after power on |

## 2 Interface

4 wire SPI: `CS` low active, `A0` (0 command, 1 data), `SI` MSB first, `SCL` (data latched on the rising
edge), up to 20 MHz. The parallel buses can read the status byte and the RAM, the serial interfaces can't.

## 3 RAM and addressing

The RAM is page organised like the SSD1306: 8 (9) pages of 132 bytes, a byte holds 8 vertical pixels with
bit 0 = top row of the page. The column address increments after every data write and stops at 131 (no wrap
into the next page), so every page is addressed separately: page address B0h | page, column address
10h | high nibble, 00h | low nibble, then the bytes of the page. The 128 pixel modules start at RAM column 0
or 4 depending on the glass; the SEG direction command (A0h / A1h) mirrors the column mapping and changes
which end the unused 4 columns are at.

## 4 Command set

| Code | Function | Reset |
|---|---|---|
| AEh / AFh | display off / on | off |
| 40h .. 7Fh | display start line 0 .. 63 (vertical scroll) | 0 |
| B0h .. B8h | page address 0 .. 8 | 0 |
| 10h .. 1Fh | column address upper 4 bits | 0 |
| 00h .. 0Fh | column address lower 4 bits | 0 |
| A0h / A1h | SEG direction normal / reverse (ADC select, horizontal mirror) | normal |
| A6h / A7h | normal / inverse display | normal |
| A4h / A5h | all points off (normal) / on | normal |
| A2h / A3h | LCD bias 1/9 / 1/7 (ST7567: 1/9 / 1/7 at 1/65 duty) | 1/9 |
| C0h / C8h | COM output scan direction normal / reverse (vertical mirror) | normal |
| E0h / EEh | read-modify-write / end | |
| E2h | software reset | |
| 28h .. 2Fh | power control: booster (04h), voltage regulator (02h), voltage follower (01h) | all off |
| 20h .. 27h | V0 regulator resistor ratio 0 .. 7 (Rb/Ra) | 4 (ST7565/UC1701), 0 (ST7567) |
| 81h, 00h .. 3Fh | electronic volume (contrast) 0 .. 63, double byte | 32 |
| ACh / ADh, mode | static indicator off / on (ST7565, UC1701) | off |
| F8h, 00h / 01h / 03h | booster ratio 2x..4x / 5x / 6x (ST7565, UC1701; not on the ST7567) | 4x |
| E3h | NOP | |

Status read (parallel bus): bit 7 busy, bit 6 ADC (SEG direction), bit 5 display off, bit 4 reset.

Typical init: `E2h, A2h, A0h, C0h, 40h, [F8h 00h], 2Ch, 2Eh, 2Fh (with ~50 ms between the power steps),
20h | ratio, 81h volume, A6h, A4h, AFh`.

## 5 The vic head `src/head/ST7565.h`

```cpp
vic::head::ST7565<Controller = ST7565_ST7565,                  // ST7565_ST7565, ST7565_ST7567, ST7565_UC1701
                  Screen_Size_X = 128, Screen_Size_Y = 64,    // logical size, 64 x 128 for orientation_90 / 270
                  Orientation = drv::orientation_0,           // done in software
                  Column_Offset = 0,                          // first RAM column of the panel (0 or 4)
                  Contrast = 0x20, Resistor_Ratio = 6, Bias_1_7 = false>
ST7565(io::handle_type device);
```

- io layer: `io::write()` option 0 = command, 1 = data (the A0 line), SPI mode 0 or 3.
- init: software reset, bias, SEG / COM direction normal, start line 0, booster ratio 4x (not for the ST7567),
  power control 2Ch / 2Eh / 2Fh with 50 / 50 / 10 ms, resistor ratio, electronic volume, normal display,
  display on, clear, present.
- Framebuffer: pages x 128 bytes (bit 0 = top row) in physical orientation, `present()` sends every page with
  B0h | page, 10h | (offset >> 4), 00h | (offset & 0Fh) and 128 bytes.
- `display_enable()` = AFh / AEh, `display_contrast()` = 81h, level / 4, `display_inverse()` = A7h / A6h,
  `shutdown()` = AEh.
- Not covered: icon page 8, static indicator, read-modify-write, scrolling with the start line.
