# ST7565 programming summary

Source: Sitronix, *ST7565R 65 x 132 Dot Matrix LCD Controller/Driver*, Ver 1.5, 2006/03/10, 72 pages (`ST7565.pdf`).
This is the programming view of the ST7565R datasheet: interfaces, RAM layout, command set, orientation bits, LCD
power circuit and sequences. The ST7565R, the Sitronix ST7567 and the UltraChip UC1701x are command compatible and
drive the common 128 x 64 COG LCD modules (ERC12864, DOGM128, Nokia 1202 style ...); the vic head
`src/head/ST7565.h` drives all three. Section 1.1 compares the three chips, the details of the other two are in
`ST7567.md` (Sitronix *ST7567 65 x 132 Dot Matrix LCD Controller/Driver*, `ST7567.pdf`) and `UC1701.md` (UltraChip
*UC1701x 65x132 STN Controller-Driver*, `UC1701.pdf`). Section 8 describes the head and the review against the
three datasheets. Page numbers refer to `ST7565.pdf`.

## 1 Overview

| Item | Value |
|---|---|
| Panel | up to 132 segments x 65 commons (64 rows + 1 icon row COMS), 128 x 64 modules use 128 of the 132 columns |
| RAM | 65 x 132 bit = 8580 bit in 9 pages, page 8 is the icon row (only D0 used) |
| Duty | selected by pins SEL3..SEL1: 1/65 (000), 1/49 (001), 1/33 (010), 1/55 (011), 1/53 (100) |
| Supplies | VDD 1.8 .. 3.3 V (logic), VDD2 2.4 .. 3.3 V (booster input), V0 3.0 .. 12.0 V (features page), VOUT max 13.5 V |
| LCD voltage | internal booster 2x .. 6x (external capacitors), regulator with VREG 2.1 V, 8 resistor ratios, 64 step electronic volume, follower for V1..V4; or external supplies |
| Interfaces | 8 bit 6800 or 8080 parallel (P/S = H, C86 selects), 4-line SPI write only (P/S = L) |
| Extras | static indicator (FR / FRS), master / slave (M/S), external display clock (CLS, CL), external V0 resistors (IRS = L), high power mode (/HPM = L), read-modify-write, power save (sleep / standby) |
| Oscillator | internal RC, fOSC typ. 20 kHz (1/65, 1/33 duty) or 30 kHz (1/49, 1/53, 1/55 duty), frame rate fOSC / 260 at 1/65 duty (77 Hz typ.) |
| Reset | /RES pin (level, low >= 1 us at 3.3 V), required after power on; software reset E2h for a subset of registers |

State after /RES (p. 40): display off, normal display, ADC normal, power control 000 (all LCD supply circuits off),
SPI shift register cleared, bias 1/9 (1/65 duty; 1/8 at 1/49, 1/55, 1/53; 1/6 at 1/33), all points on off, power
saver off, V0 internal resistors Ra / Rb disconnected, SEG and COM at VSS, read-modify-write off, static indicator off
(register 00), start line 0, column 0, page 0, COM normal, electronic volume 20h (32), test mode off. The resistor
ratio value after reset is not stated (ST7567 and UC1701x: 4). RAM content is undefined after power on.

## 2 Interfaces

| Pin | Function |
|---|---|
| P/S | H: 8 bit parallel, L: 4-line SPI (write only, D5..D0 fixed to H, /RD and /WR fixed) |
| C86 | H: 6800 (E, R/W), L: 8080 (/RD, /WR) |
| /CS1, CS2 | chip active when /CS1 = L and CS2 = H; inactive: D7..D0 high impedance, SPI shift register and counter reset |
| A0 | H: display data, L: command / status |
| /RD (E), /WR (R/W) | 8080: read strobe, write strobe (data latched on the rising /WR edge); 6800: E high active enable, R/W = H read |
| D7..D0 | data bus; SPI: D7 = SI, D6 = SCL |
| /RES | low = reset, level triggered |

| A0 | 6800 R/W | 8080 /RD, /WR | Function |
|---|---|---|---|
| 1 | 1 | 0, 1 | read display data |
| 1 | 0 | 1, 0 | write display data |
| 0 | 1 | 0, 1 | status read |
| 0 | 0 | 1, 0 | write command |

4-line SPI (p. 24): SI is sampled on the rising SCL edge, D7 first; after the 8th clock the byte is converted to
parallel data and A0 is sampled on that 8th rising edge (1 = display data, 0 = command). There is no read in SPI
mode; reflections and noise on SCL are a known risk.

Reading (parallel only): writes go through a bus holder directly into the RAM; a read returns the bus holder content
of the previous access, so a dummy read is required after every address set or write before the first valid data
byte (Figure 2). The busy flag (status bit 7) does not need to be polled if the cycle time is met: commands execute
in internal timing, no execution times are specified.

Status byte (A0 = 0, read): `BUSY ADC ON/OFF RESET 0 0 0 0`. BUSY = 1 internal processing or reset; ADC = 0 normal
(column n -> SEG n), 1 reverse (column 131 - n -> SEG n); ON/OFF = 0 display on, 1 display off; RESET = 1 reset in
progress.

| /WR high tCCHW, E high tEWHW (write) | 80 | 180 | 280 |
| /RD low tCCLR / E low tEWLR (read) | 140 / 80 | 220 | 360 |
| /RD high tCCHR / E high tEWHR (read) | 80 / 140 | 180 | 280 |

Rise and fall times <= 15 ns, levels at 20 % / 80 % of VDD. In the 6800 mode the active (E high) read pulse is the
140 ns value; the 2.7 V and 1.8 V tables list the same values for both buses.

## 3 Display data RAM

The RAM is 9 pages of 132 bytes (p. 26, Figure 4), organised like the SSD1306 page mode. A byte holds 8 vertical
pixels of one column: D0 is the top row
of the page, D7 the bottom row, 1 = pixel on (normal display). Page 8 is the icon row, only D0 is used; it is always
output on COMS, independent of the start line (the 65th line at 1/65 duty, the 49th / 33rd / 55th / 53rd line at the
other duties).

- Page address: B0h | page (0 .. 8), must be set again for every page change.
- Column address: 10h | upper nibble, 00h | lower nibble (0 .. 131 = 83h). The column increments after every data
  read or write and stops at 83h; it never wraps into the next page, so page 0 column 83h to page 1 column 0 needs
  both addresses set again.
- ADC (A0h / A1h, Table 4): ADC = 0 maps column 0 to SEG0 and column 83h to SEG131, ADC = 1 maps column 83h to SEG0.
  A 128 pixel module wired to SEG0..SEG127 uses columns 0..127 with A0h and columns 4..131 with A1h, so the 128
  pixel modules start at RAM column 0 or 4 depending on the glass and the ADC setting; A0h / A1h changes which end
  the unused 4 columns are at.
- Display start line (40h | line, 0 .. 63): the RAM line shown on the top COM (COM0 with normal COM direction, COM63
  with reverse). Changing it scrolls the whole picture vertically without rewriting the RAM.
- Read-modify-write (E0h .. EEh): after E0h a data read does not increment the column, a data write does; EEh returns
  the column to the value at E0h. Sequence: E0h, page, column, dummy read, then read / modify / write per byte, EEh.
- Display normal / reverse, all points on and display on / off act on the display latch only, the RAM is unchanged.
  RAM access is asynchronous to the display, no flicker.

A full 128 x 64 frame is 8 pages of 128 bytes, each page addressed separately: `B0h | page, 10h | (col >> 4),
00h | (col & 0Fh)`, then the bytes.

## 4 Command set

All commands are written with A0 = 0. Codes in hex, the reset column is the state after /RES.

| Code | Command | Parameter | Reset | Function |
|---|---|---|---|---|
| AEh / AFh | Display off / on | - | AEh | display off keeps the RAM; AEh while all points on (A5h) enters power save |
| 40h .. 7Fh | Display start line | line 0 .. 63 | 40h | top display line (vertical scroll) |
| B0h .. B8h | Page address | page 0 .. 8 | B0h | page 8 = icon row |
| 10h .. 1Fh | Column address upper | A7..A4 | 0 | upper nibble |
| 00h .. 0Fh | Column address lower | A3..A0 | 0 | lower nibble |
| (read, A0 = 0) | Status read | - | - | BUSY ADC ON/OFF RESET 0000 |
| (write, A0 = 1) | Display data write | data | - | column + 1 |
| (read, A0 = 1) | Display data read | data | - | column + 1, dummy read after address set |
| A0h / A1h | ADC select | - | A0h | SEG direction normal / reverse (horizontal mirror) |
| A6h / A7h | Display normal / reverse | - | A6h | A7h: RAM 0 = pixel on |
| A4h / A5h | Display all points | - | A4h | A5h forces all pixels on, has priority over A6h / A7h |
| A2h / A3h | LCD bias | - | A2h | 1/65: 1/9 / 1/7; 1/49, 1/55, 1/53: 1/8 / 1/6; 1/33: 1/6 / 1/5 |
| E0h | Read-modify-write | - | off | column increments on write only |
| EEh | End | - | - | leave read-modify-write, column restored |

| C0h / C8h | COM output mode | `1100 Dxxx` | C0h | COM0 -> COM63 / COM63 -> COM0 (vertical mirror) |
| 28h .. 2Fh | Power control | `0010 1 VB VR VF` | 28h | VB booster, VR regulator, VF follower on |
| 20h .. 27h | V0 resistor ratio | `0010 0 R2 R1 R0` | not stated | (1 + Rb/Ra) = 3.0 + 0.5 x R |
| 81h, xx | Electronic volume | 00h .. 3Fh | 20h | double byte, 00h = lowest V0, 3Fh = highest; set 20h when unused |
| ACh | Static indicator off | - | off | single byte |
| ADh, xx | Static indicator on | 00h off, 01h blink ~1 s, 02h blink ~0.5 s, 03h on | 00h | double byte |
| F8h, xx | Booster ratio | 00h 2x / 3x / 4x, 01h 5x, 03h 6x | - | double byte, 00h when not used |

| E3h | NOP | - | - | |
| FCh .. FFh | Test | - | - | do not use, cleared by /RES, E2h or E3h |

Double byte commands (81h, ADh, F8h): after the first byte only the register set byte is accepted, the mode ends with
it; both bytes have to be sent back to back. The test command is `1111 11xx` in the command description (p. 49) but
`1111 xxxx` in Table 16 (p. 50), which would include F8h; the description is the consistent one. The datasheet
recommends refreshing the operating modes periodically because noise can change internal registers (p. 49, 54).

## 5 Orientation

Two bits mirror the picture: ADC (A0h / A1h, SEG direction) and the COM output mode (C0h / C8h). 90 degree rotations
are not possible in the controller. The start line can additionally shift the picture vertically.

| Orientation | ADC | COM | First RAM column of a 128 column panel on SEG0..SEG127 |
|---|---|---|---|
| `orientation_0` | A0h | C0h | 0 |
| `orientation_0m` | A0h | C8h | 0 |
| `orientation_180m` | A1h | C0h | 4 |
| `orientation_180` | A1h | C8h | 4 |

The vic head does not use these bits: SEG and COM direction stay at A0h / C0h and all eight orientations (including
90 / 270) are done in software by mapping the logical pixel into the physical framebuffer (section 8). Which hardware
setting shows a module upright depends on the glass; the head notes that DOGM128 / ERC12864 modules are upright with
`orientation_180` or `orientation_0m`.

## 6 Power, reset and initialisation

### 6.1 Reset

/RES low resets everything listed in section 1 (items 1 .. 19, p. 40); the reset command E2h only resets items
11 .. 19: read-modify-write, static indicator, start line, column, page, COM direction, resistor ratio, electronic
volume (20h) and test mode. Display on/off, normal/reverse, ADC, bias, power control and power save are not touched
by E2h. The datasheet requires the /RES pin for the initialisation after power on, the reset command must not be
used instead (p. 44). While /RES is low the oscillator and display timing stop, CL, FR, FRS, /DOF are high, SEG and
COM output VSS and an internal resistor discharges V0. Control inputs must not float (over current).

### 6.2 LCD power circuit

Power control set (`28h | VB VR VF`) combinations (Table 8):

| Code | Booster | Regulator | Follower | Use |
|---|---|---|---|---|
| 2Fh | on | on | on | internal supply only (VDD2 boosted) |
| 2Bh | off | on | on | external VOUT, internal regulator and follower |
| 29h | off | off | on | external V0, internal follower |
| 28h | off | off | off | external V0..V4 |

Booster: the ratio is set by the capacitor wiring (Figure 7: 2x, 3x, 4x, 5x, 6x, C1 = 1.0 .. 4.7 uF) and F8h
(00h for 2x / 3x / 4x, 01h 5x, 03h 6x); VOUT <= ratio x VDD2 and VOUT must stay below 13.5 V. The supply circuits work
in master mode only. /HPM = L selects the high power mode for large panels (higher current, Table 21).

Regulator (p. 33): with the internal resistors (IRS = H)

`V0 = (1 + Rb/Ra) x VEV`, `VEV = (1 - alpha / 162) x VREG`, `alpha = 63 - EV` (EV = electronic volume 0 .. 63),

so `V0 = (1 + Rb/Ra) x (99 + EV) / 162 x 2.1 V`. VREG = 2.1 V (2.07 .. 2.13 V, -0.05 %/C). (1 + Rb/Ra) is
3.0, 3.5, 4.0, 4.5, 5.0, 5.5, 6.0, 6.5 for 20h .. 27h (Table 11). V0 must stay below VOUT. Example (Table 12, 13):
ratio 22h (4.0), EV 25h gives 7.0 V, the EV range covers 5.1 .. 8.4 V in 51 mV steps. With IRS = L the ratio is set
by external resistors Ra' (VSS..VR) and Rb' (VR..V0), example Ra' 340 kOhm, Rb' 1060 kOhm for 7 V (p. 35).

Bias voltages (follower, from V0): 1/9 bias V1 = 8/9, V2 = 7/9, V3 = 2/9, V4 = 1/9 x V0; 1/7 bias 6/7, 5/7, 2/7,
1/7 x V0 (the other duties use 1/8, 1/6, 1/5 accordingly). C2 = 0.1 .. 4.7 uF on V0..V4, all equal. Required order
VOUT >= V0 >= V1 >= V2 >= V3 >= V4 >= VSS.

### 6.3 Initialisation (p. 51, 52)

Built-in power used immediately after power on:

1. Power on with /RES low, wait until the supply is stable.
2. /RES high, wait for the reset to finish (< 1 ms).
3. LCD bias (A2h / A3h), ADC (A0h / A1h), COM direction (C0h / C8h).
4. Resistor ratio (20h .. 27h), electronic volume (81h, xx).
5. Power control (2Fh, or the stepwise variant).
6. Initialise the RAM (pages 0 .. 8), then display on (AFh).

Steps 2 .. 5 should complete within 5 ms (panel dependent target) to avoid a dark flash from charge left in the V0..V4
capacitors. If the built-in power is not used right away, enter power save (AEh, A5h) within 5 ms after the reset,
set steps 3 and 4, leave power save (A4h) and set the power control within 5 ms.

The drivers in common use (Adafruit ST7565, u8g2) and the vic head use: `E2h, A2h, A0h, C0h, 40h, [F8h 00h], 2Ch,
2Eh, 2Fh (with ~50 ms between the power steps), 20h | ratio, 81h volume, A6h, A4h, AFh`.

### 6.4 Power save and power off

Power save is the compound AEh (display off) + A5h (all points on). With the static indicator off it is the sleep
mode (oscillator and LCD supply stopped, outputs at VSS, 0.1 uA typ.), with the static indicator on the standby mode
(LCD supply stopped, oscillator and static drive running, 5 uA typ.). RAM and registers are kept and the RAM stays
accessible. Exit: A4h (all points off), then re-enable the static indicator if used (Figure 28). /DOF goes low in
power save to switch off external supplies. The internal power supply shutdown sequence (Figure 13) is AEh, A5h.

Power off (p. 53 .. 55): power save, then /RES low, then VDD off. The V0..V4 levels must have fallen below the LCD
threshold before VDD drops below 1.8 V (tL > tH; tH up to ~100 ms depending on C2, Figure 31). The notes on p. 53
contradict each other: *15 says to apply /RES after the power save command, *16 says not to; the flow chart and the
timing diagram on p. 54 show /RES applied.

## 8 The vic head `src/head/ST7565.h`

```cpp
vic::head::ST7565<Controller = ST7565_ST7565,                  // ST7565_ST7565, ST7565_ST7567, ST7565_UC1701
                  Screen_Size_X = 128, Screen_Size_Y = 64,    // logical size, 64 x 128 for orientation_90 / 270
                  Orientation = drv::orientation_0,           // done in software
                  Column_Offset = 0,                          // first RAM column of the panel (0 or 4)
                  Contrast = 0x20, Resistor_Ratio = 6, Bias_1_7 = false>
ST7565(io::handle_type device);
```

- io layer: `io::write()` option 0 = command, 1 = data (the A0 line), SPI mode 0 or 3 (SI is sampled on the rising
  SCL edge). The head never reads, so the write only SPI of all three chips is sufficient.
- init: software reset (E2h, 5 ms), bias (A2h / A3h), SEG / COM direction normal (A0h, C0h), start line 0 (40h),
  booster ratio 4x (F8h 00h, not for the ST7567), power control 2Ch / 2Eh / 2Fh with 50 / 50 / 10 ms, resistor
  ratio (20h | ratio), electronic volume (81h, contrast), normal display (A6h), all points off (A4h), display on
  (AFh), clear, present.
- Framebuffer: pages x PHYS_X bytes (128 for the 128 x 64 panel, bit 0 = top row) in physical orientation,
  `present()` sends every page with B0h | page, 10h | (offset >> 4), 00h | (offset & 0Fh) and the PHYS_X bytes as
  one data block. `static_assert`s check the page multiple and that offset + width fits into 132 columns.
- Orientation: `to_phys()` maps the logical vertex to the physical panel; the `m` orientations mirror the panel
  top / bottom after the rotation.
- `display_enable()` = AFh / AEh, `display_contrast()` = 81h, level / 4, `display_inverse()` = A7h / A6h,
  `shutdown()` = AEh (also called by the destructor).
- Not covered: icon page 8, static indicator, read-modify-write, scrolling with the start line, status / RAM reads.

With the defaults (Resistor_Ratio 6, Contrast 20h) the regulator targets V0 = 6.0 x 131 / 162 x 2.1 V = 10.2 V on the
ST7565R and the ST7567 and VLCD = 7.517 x 131 / 162 x 1.68 V = 10.2 V on the UC1701x.

Review against the three datasheets (no code was changed):

1. Command codes, double byte sequences, page / column addressing, bit order and the A0 convention match all three
   datasheets.
2. Power on reset: the head only sends the software reset E2h. The ST7565R (p. 44, 51) and the ST7567 require a
   hardware reset on /RES (RSTB) after power on, E2h leaves display mode, ADC, bias and power control untouched. The
   pulse has to come from the io layer (`io::init()`) or the board. The UC1701x has a power on reset, there E2h is
   sufficient (wait 5 .. 10 ms after power on, 6 ms after an RST pulse).
3. Power up order: the datasheet flows set bias, directions, resistor ratio and electronic volume first and then
   switch on the power control, all within 5 ms after the reset; the head switches booster, regulator and follower
   in three steps over 110 ms and sets ratio and volume afterwards. This works (the display is still off), but it is
   not the datasheet flow; the UC1701x needs no waits between the power steps at all.
4. ST7567: the head assumes there is no booster ratio command. The ST7567 has F8h + BL (00h 4x, 01h 5x); skipping it
   leaves the reset value 4x, the same as F8h 00h. The ST7567 application voltage guide uses 5x for all duties, and
   at VDD2 = 2.8 V a 4x booster cannot reach the 10.2 V default target (see `ST7567.md`).
5. UC1701x: F8h 00h is a NOP on this chip (harmless). With Resistor_Ratio 6 the datasheet limits PM to 48 for
   VLCD <= 11.5 V, `display_contrast(255)` sets PM 63 (12.6 V), above the recommended maximum.
6. `shutdown()` only sends AEh. On the ST7565R and ST7567 the booster and regulator keep running; the datasheet power
   off is power save (AEh, A5h) followed by /RES before VDD off. On the UC1701x AEh is the sleep mode, the datasheet
   recommends the reset (E2h) to drain the capacitors before power off.
7. Corrected in this summary against the previous version: the UC1701x datasheet has no 3-wire SPI (only the 4-wire
   S8 bus); the ST7567 resistor ratio resets to 4, not 0, and the ST7567 does have the F8h booster command; the
   static indicator commands are NOPs on the UC1701x; the ST7565R datasheet gives no reset value for the ratio.
