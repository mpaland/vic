# ST7920 programming summary

Source: Sitronix *ST7920 Chinese Fonts built in LCD controller/driver* V3.3 (`ST7920.pdf`). The ST7920 drives
the common 128 x 64 graphic LCD modules (and 192 x 32 / 256 x 32 variants); it has a text mode with a Chinese
font ROM and a graphic mode with a 64 x 256 bit GDRAM. The vic head `src/head/ST7920.h` uses the graphic mode.

## 1 Overview

| Item | Value |
|---|---|
| Drivers | 32 common x 64 segment per chip, 128 x 64 modules use the 2 line (2 x 32 row) arrangement with segment extenders |
| RAM | DDRAM 64 x 16 bit (text, 4 lines x 16 characters), CGRAM 64 x 16 bit (4 user characters 16 x 16), GDRAM 64 x 256 bit (graphic) |
| Font ROM | 8192 Chinese 16 x 16 characters (GB / BIG5), 126 half width 8 x 16 characters |
| Supplies | 2.7 .. 5.5 V, internal or external LCD voltage |
| Interfaces | 8 bit and 4 bit parallel (PSB = 1), clock synchronised serial (PSB = 0: CS, SID, SCLK) |
| Oscillator | internal RC 540 kHz, instruction time 72 us (clear 1.6 ms) |

## 2 Interfaces

Parallel: `RS` (0 instruction, 1 data), `R/W`, `E` like the HD44780, 8 bit or 4 bit (two nibbles, high first).
Serial (PSB = 0): a transfer is a sync byte `1 1 1 1 1 RW RS 0` (F8h = write instruction, FAh = write data)
followed by the data byte split into two bytes, high nibble then low nibble, each in the upper four bits
(`D7 D6 D5 D4 0 0 0 0`, `D3 D2 D1 D0 0 0 0 0`). The serial interface has no read back; the busy flag can be
read on the parallel bus (RS = 0, R/W = 1, bit 7). Every instruction / data byte needs 72 us, clear needs
1.6 ms; without the busy flag the host must wait these times.

## 3 Instruction set

Basic instructions (RE = 0):

| Code | Function | Time |
|---|---|---|
| `0000 0001` | clear DDRAM (20h), AC = 0 | 1.6 ms |
| `0000 001x` | return home | 72 us |
| `0000 01 I/D S` | entry mode (increment, shift) | 72 us |
| `0000 1 D C B` | display on/off, cursor, blink | 72 us |
| `0001 S/C R/L xx` | cursor / display shift | 72 us |
| `001 DL x RE 0 x x` | function set: DL = 1 8 bit, RE = 1 extended instruction set | 72 us |
| `01 AC[5:0]` | set CGRAM address | 72 us |
| `1 AC[6:0]` | set DDRAM address (AC6 = 0) | 72 us |
| data write / read | DDRAM / CGRAM / GDRAM through the current address | 72 us |

Extended instructions (RE = 1):

| Code | Function |
|---|---|
| `0000 0001` | standby |
| `0000 001 SR` | SR = 1 vertical scroll address, SR = 0 CGRAM address |
| `0000 01 R1 R0` | reverse display of a DDRAM line (toggle) |
| `001 DL x 1 G 0` | extended function set: G = 1 graphic display on |
| `01 AC[5:0]` | scroll address (SR = 1) |
| `1 AC[6:0]` then `1 AC[3:0]` | set GDRAM address: vertical address 0 .. 63 first, then horizontal address 0 .. 15 |

RE keeps its value between instructions; change it only with the function set instruction (basic 30h,
extended 34h, extended + graphic on 36h).

## 4 GDRAM layout

The GDRAM is 64 rows (vertical address) x 16 words of 16 bit (horizontal address), bit 15 of a word is the
left pixel. A 128 x 64 panel shows the upper 32 rows from vertical addresses 0 .. 31, horizontal addresses
0 .. 7, and the lower 32 rows from the SAME vertical addresses 0 .. 31 at horizontal addresses 8 .. 15. After
setting the address the words are written high byte first; the horizontal address increments after every word
and wraps after 15, so one vertical address takes a row of the upper half (16 bytes) followed by the matching
row of the lower half (16 bytes).

## 5 The vic head `src/head/ST7920.h`

```cpp
vic::head::ST7920<Screen_Size_X = 128, Screen_Size_Y = 64,   // logical size, 64 x 128 for orientation_90 / 270
                  Orientation = drv::orientation_0>           // done in software
ST7920(io::handle_type device);
```

- io layer: `io::write()` option 0 = instruction (RS = 0), 1 = data (RS = 1); the serial sync byte and the
  nibble split are the io layer's job, as is the 72 us pacing (or the busy flag on the parallel bus). The head
  only waits after power on (50 ms), the first function set (1 ms) and the clear (2 ms).
- init: 30h, 30h, 0Ch (display on), 01h, 06h, 34h (extended), 36h (graphic on), clear, present.
- Framebuffer: 1024 bytes row organised (16 bytes per row, bit 7 = left pixel) in physical orientation.
  `present()` writes 32 vertical addresses: 80h | y, 80h, 16 bytes of row y, 16 bytes of row y + 32.
- `display_enable()` toggles the graphic display bit (36h / 34h), `shutdown()` = 34h, 30h, 08h.
- Not covered: text mode, CGRAM, scrolling, standby.
