# SSD1351 programming summary

Source: Solomon Systech *SSD1351 128 RGB x 128 Dot Matrix OLED/PLED Segment/Common Driver with Controller*
Rev 1.3 (`SSD1351.pdf`), the controller of the 1.5" 128 x 128 and 1.27" 128 x 96 RGB OLED modules. The last
section describes the vic head `src/head/SSD1351.h`.

## 1 Overview

| Item | Value |
|---|---|
| Panel | 128 RGB x 128 (384 segments, 128 commons) |
| GDDRAM | 128 x 128 x 18 bit, 65k (16 bit) or 262k (18 bit) color formats |
| Supplies | VDD 2.4 .. 2.6 V or internal regulator from VCI 2.4 .. 3.5 V, VCC 10 .. 18 V panel |
| Interfaces | 8 / 16 / 18 bit 6800 / 8080, 4 wire SPI, 3 wire SPI; write only on SPI |
| Brightness | contrast per color C1h (256 steps each), master contrast C7h (16 steps), 63 entry gray scale table |
| Clock | Fosc divided by 1 .. 1024 (B3h), reset D1h |

Unlike the SSD1331 the SSD1351 has no graphic acceleration commands (no line / rectangle / copy).

## 2 Interface

4 wire SPI: `CS#`, `D/C#` (0 command, 1 parameters / data), `SCLK`, `SDIN`, MSB first, clock cycle >= 100 ns.
Command parameters are sent with D/C# = 1. Several commands (A2h, B1h, B3h, BBh, BEh) are locked by default
and need `FDh B1h` to unlock.

## 3 RAM organisation and pixel format

Column (15h) and row (75h) windows 0 .. 127, inclusive; after 5Ch the pixels are written along the columns
(A0h A[0] = 0) or rows (A[0] = 1) with wrap inside the window. 65k format (A0h A[7:6] = 00 / 01): one 16 bit
word per pixel, `C4..C0 B5..B0 A4..A0` (MSB first, two bytes on SPI); color A is the first segment of a
pixel, A[2] = 1 swaps the sequence to C, B, A. 262k formats (A[7:6] = 10 / 11): 3 bytes per pixel.

Reference init (Adafruit): `FD 12, FD B1, AE, B3 F1, CA 7F, A0 74, 15 00 7F, 75 00 7F, A1 00, A2 00, B5 00,
AB 01, B1 32, BE 05, A6, C1 C8 80 C8, C7 0F, B4 A0 B5 55, B6 01, AF` (A0h 74h = 65k, COM split, COM scan remap,
color swap).

## 5 The vic head `src/head/SSD1351.h`

```cpp
vic::head::SSD1351<Screen_Size_X = 128, Screen_Size_Y = 128,   // logical size, swapped for orientation_90 / 270
                   Orientation = drv::orientation_0,           // remap bits, orientation_0m for the Adafruit modules
                   RGB_to_BGR  = true>                         // A0h A[2]
SSD1351(io::handle_type device);
```

- io layer: `io::write()` option 0 = command, 1 = parameters and pixel data; `io::read()` option 1 reads two
  pixel bytes after 5Dh on the parallel bus, SPI returns `color::none`.
- init: the reference sequence with the remap from the orientation table (65k, COM split, vertical increment
  for the rotated orientations, column remap = horizontal mirror, COM scan remap = vertical mirror, color swap),
  MUX = rows - 1, clear.
- Drawing: like the SSD1331 head without GAC, the window (15h / 75h / 5Ch) is set per primitive and RGB565
  pixels are streamed in blocks of 32 with write pointer tracking.
- `display_enable()` = AFh / AEh, `display_brightness()` = C7h, `display_contrast()` scales the three channel
  contrasts (C8h 80h C8h), `display_inverse()` = A7h / A6h, `shutdown()` = AEh.
- Not covered: 262k color formats, scrolling, gray scale table, the 128 x 96 start line offset (set A1h 60h).
