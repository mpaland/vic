# UC1701 programming summary

Source: UltraChip, *UC1701x 65x132 STN Controller-Drivers*, MP Specifications Revision A1.0, November 7, 2008,
48 pages (`UC1701.pdf`). This is the programming view of the datasheet: interfaces, RAM layout, command set,
orientation, LCD voltage generation and sequences. The UC1701x is command compatible with the Sitronix ST7565R and
ST7567 and is driven by the vic head `src/head/ST7565.h` with `Controller = ST7565_UC1701`. The head, the comparison of
the three chips and the ST7565R details are in `ST7565.md`, the ST7567 in `ST7567.md`. Section 8 lists the UC1701x
specific points of the review. Page numbers refer to `UC1701.pdf`.

## 1 Overview

| Item | Value |
|---|---|
| Panel | 132 segments (SEG1..SEG132) x 64 commons (COM1..COM64) + icon common CIC, STN, DCC driver architecture |
| RAM | 65 x 132 bit, 8 pages + page 8 for the icon row |
| Duty | pins DT2, DT1: 00 1/65, 01 1/49, 10 1/33, 11 1/55; bias 1/9 .. 1/5 by command (BR) |
| Supplies | VDD 1.65 .. 3.6 V (typ. 1.8 .. 3.3 V) logic, VDD2 / VDD3 2.4 .. 3.6 V (typ. 2.5 .. 3.3 V) pump and analog, VDD <= VDD2/3 <= VDD + 1.3 V (pin description; the absolute maximum table allows 1.2 V difference) |
| LCD voltage | internal charge pump ("7x") with on-chip pumping capacitors, VLCD 3.9 .. 11.5 V, regulator with 8 resistor ratios and 64 step electronic volume, temperature compensation -0.05 or -0.11 %/C |
| External parts | CB0, CB1 2.2 uF / 5 V (or 100 .. 250 x LCD load), CL 330 nF / 25 V optional on VLCD, RL 3.3 .. 10 MOhm optional drain resistor |
| Interfaces | BM[1:0]: 11 6800 8 bit, 10 8080 8 bit, 00 or 01 S8 4-wire SPI (write only); no I2C (ordering table) |
| Reset | power on reset (~5 ms), software reset E2h, RST pin optional (on-chip RC filter, tie to VDD when unused) |
| Extras | cursor update mode (read-modify-write), column / page wrap around and temperature coefficient (APC0), sleep mode via display enable |
| Not present (vs ST7565R) | booster ratio and static indicator (accepted as NOP), master / slave, external clock |

Defaults after power on reset and system reset (control register table, p. 10): SL = 0, CA = 0, PA = 0, BR = 0,
PM = 20h (32), PC = 20h (PC[5:3] = 100b resistor ratio, PC[2:0] = 000b booster / regulator / follower off), CR = 0,
cursor update mode off, DC = 0 (inverse off, all pixels on off, display off = sleep), MX = MY = 0, APC0 = 90h
(TC = -0.11 %/C, no wrap around).

## 2 Interfaces

| Pin | Function |
|---|---|
| BM1, BM0 | bus mode, see the table below |
| CS0 | chip select, low active; high: D[7:0] high impedance, bus state initialised (S8) |
| CD | 0: control (command / status), 1: display data |
| WR0 | 8080: /WR (write strobe); 6800: R/W |
| WR1 | 8080: /RD (read strobe); 6800: E (enable) |
| D[7:0] | data bus; S8: D7 = SDA, D6 = SCK, D5..D0 unused (connect to VDD or VSS) |
| RST | low: reset of all control registers; optional |
| DT2, DT1 | duty |

| BM[1:0] | Bus | Access |
|---|---|---|
| 11 | 6800, 8 bit | read / write |
| 10 | 8080, 8 bit | read / write |
| 00, 01 | S8, 4-wire SPI with 8 bit tokens | write only |

| CD | Write cycle | Read cycle |
|---|---|---|
| 0 | command | get status |
| 1 | display data | display data |

S8 (p. 26): 8 bits MSB first are latched on eight rising SCK edges; CD is examined when SCK goes low for the LSB (D0)
of each token; a data byte is written into the RAM on the rising edge of the last SCK pulse. CS0 high resets the bus
cycle.

Parallel reads: the RAM read path is a two-stage pipeline, every change of the address (Set CA or Set PA, in parallel
or serial mode) requires one dummy read before valid data; writes have no pipeline (data goes to the RAM on the rising
edge of the write pulse). Status byte (CD = 0, read): `BZ MX DE RST 0 0 0 0`; BZ = 1 busy (commands are accepted only
with BZ = 0), MX = LC[0], DE = 1 display enabled, RST = 1 reset in progress. Note the polarity: DE = 1 means display
on, the ST7565R and ST7567 report display off with 1.

AC timing (p. 39 .. 42, Ta -30 .. 85 C, min values in ns unless noted):

| Parameter | 2.5 V <= VDD < 3.3 V | 1.65 V <= VDD < 2.5 V |
|---|---|---|
| 8080 cycle tCY80 read / write | 120 / 80 | 240 / 160 |
| 8080 pulse width tPWR80 (read) / tPWW80 (write) | 60 / 40 | 120 / 80 |
| 8080 high pulse width tHPW80 read / write | 60 / 40 | 120 / 80 |
| 8080 data setup tDS80 / hold tDH80 | 30 / 0 | 60 / 0 |
| 8080 read access tACC80 (max) / output disable tOD80 (min), CL 100 pF | 60 / 20 | 100 / 50 |
| CD setup / hold, CS setup / hold (parallel) | 0 / 5, 5 / 5 | 0 / 0, 5 / 5 |
| 6800 cycle tCY68 read / write, pulse width read / write | 120 / 80, 60 / 40 | 240 / 160, 120 / 80 |
| 6800 read access tACC68 (max) | 60 | 100 |
| S8 cycle tCYS8 (write) | 30 (33 MHz) | 60 (16.7 MHz) |
| S8 SCK low / high tLPWS8, tHPWS8 (write) | 15 / 15 | 30 / 30 |
| S8 SDA setup tDSS8 / hold tDHS8 | 12 / 0 | 24 / 0 |
| S8 CD setup / hold, CS setup / hold | 0 / 0, 5 / 5 | 0 / 0, 10 / 10 |
| RST low pulse tRW | 3 us | 3 us |
| RST to first WR pulse tRD | 6 ms | 6 ms |

The S8 table also lists "read" cycle values (100 / 130 ns) although the bus is write only.

COG note (p. 9): the peak IDD during fast RAM writes reaches ~15 mA; VDD / VSS ITO resistance must keep the on-chip
VDD above 1.65 V.

## 3 Display data RAM

The RAM is 65 x 132 bit: pages PA 0 .. 7 with 8 lines each and page 8 for the icon output CIC (p. 29, 30). A byte
holds 8 vertical pixels of one column, D0 is the top line of the page (line address 8 x PA), 1 = pixel on.

- Page address: B0h | PA (0 .. 8). Column address: 00h | CA[3:0], 10h | CA[7:4] (0 .. 131).
- The column increments after every data read or write. Wrap around is controlled by APC0 WA[1:0] (CA and PA wrap
  enable, both disabled at reset); the datasheet gives no further detail of the wrap behaviour. The sample power up
  sequence enables both (FAh, 93h).
- MX (A0h / A1h): the RAM column used is CA (MX = 0) or 131 - CA (MX = 1), i.e. column 0 is SEG1 with MX = 0 and
  SEG132 with MX = 1. MX is applied when data is written; the DDRAM chapter says the RAM has to be rewritten after
  changing MX, the command description says MX has immediate effect on the image (contradiction in the datasheet).
- Scroll line SL (40h | SL, 0 .. 63): the first line period of a frame outputs RAM line SL, then Line = (Line + 1)
  mod 64. With MY = 1 the first line is (SL + MR - 1) mod 64 and the line counts down (MR = mux rate). CIC is never
  scrolled; the COM electrode order itself is fixed.
- Cursor update mode (E0h): CR = CA, the column increments on writes only and does not wrap; EEh restores CA = CR.
  This is the read-modify-write of the ST7565R.

both are writes.

## 5 Orientation

MX (A0h / A1h) mirrors horizontally, MY (C0h / C8h) vertically, the scroll line shifts vertically; no 90 degree
rotation. The mapping to the vic orientations is the same as for the ST7565R (`ST7565.md` section 5): with A1h a 128
pixel panel on SEG1..SEG128 starts at RAM column 4. Because MX is applied on write, set it before filling the RAM.
The vic head keeps A0h / C0h and does all orientations in software.

## 6 Power, reset and initialisation

### 6.1 Reset and operating modes

Power on reset waits ~5 ms for VDD and then runs the system reset; RST low or E2h trigger the system reset as well
(p. 31). The operating modes (Table 4):

| Mode (OM) | Entered by | Host interface | Clock | LCD drivers | Charge pump | Draining circuit |
|---|---|---|---|---|---|---|
| Reset (00) | E2h, RST low, power on | active | off | off | off | on |
| Sleep (10) | AEh (DC[2] = 0) | active | off | off | off | on |
| Normal (11) | AFh (DC[2] = 1) | active | on | on | on | off |

The datasheet contradicts itself in two places: the text says sleep keeps the charge in CB0, CB1 and CL and only the
reset drains them, Table 4 lists the draining circuit on in sleep; and the command description says the system reset
sets all control registers to default, while the hardware / software reset table on p. 31 (apparently taken from the
ST7567, it even lists a booster level) says E2h does not reset display enable, inverse, MX, BR and power control.
Sleep draws typically under 2 uA but the charged capacitors leak through the COM drivers, so the datasheet
recommends sleep only for short display off periods and the reset for long ones. When leaving sleep or reset the
drivers are enabled only after VLCD and VBIAS are ready (built-in "power ready" check).

### 6.2 LCD voltage

`VLCD = (1 + Rb/Ra) x Vev x (1 + (T - 25) x CT %)`, `Vev = (1 - (63 - PM) / 162) x VREF`, VREF = 1.68 V, CT the
temperature coefficient (APC0 TC). At 25 C: `VLCD = (1 + Rb/Ra) x (99 + PM) / 162 x 1.68 V`. Keep VLCD below 11.5 V
over temperature (VLCD quick reference, p. 19):

| PC[5:3] | 1 + Rb/Ra | VLCD at PM = 0 | VLCD at max PM |
|---|---|---|---|
| 000b | 3.769 | 3.87 V | 6.33 V (PM 63) |
| 001b | 4.396 | 4.51 V | 7.38 V (63) |
| 010b | 5.020 | 5.15 V | 8.43 V (63) |
| 011b | 5.643 | 5.79 V | 9.48 V (63) |
| 100b (default) | 6.266 | 6.43 V | 10.53 V (63) |
| 101b | 6.891 | 7.08 V | 11.51 V (62) |
| 110b | 7.517 | 7.72 V | 11.46 V (48) |
| 111b | 8.143 | 8.36 V | 11.48 V (37) |

The defaults (100b, PM 32) give 8.49 V, the value used for the power consumption table. Bias ratio BR = VLCD / VBIAS
(VBIAS = VB1+ - VB1- = VB0+ - VB0-), values as in the command table. The pump handles panels up to ~24 nF with
20 Ohm/sq ITO at VDD2/3 = 2.4 V. Software contrast fine tuning is the recommended way to match the LC Vop.

### 6.3 Power up (p. 33, 35)

Figure 8: power on (VDD and VDD2/3 in any order, no delay needed), RST low >= 1 ms, RST high, wait >= 5 ms, issue
commands, "wait for MTP-READ >= 120 ms", set bias ratio and electronic volume, AFh. The text says only 5 .. 10 ms are
needed before the first command and no further waits between enabling the charge pump, the drivers and RAM writes;
the 120 ms MTP read in the figure is not explained elsewhere (the UC1701x has no MTP commands).

Sample power up command sequence (p. 35): wait ~5 ms after VDD on, FAh 93h (wrap around on, advanced), A0h / A1h,
C0h / C8h, A2h / A3h, 81h PM, write the RAM, AFh. It contains no Set Power Control; the register table gives PC[2:0]
= 000b (off) as default, so it is not clear from the datasheet whether AFh alone starts the pump. Sending 2Fh before
AFh, as the common drivers do, is consistent with both readings.

### 6.4 Sleep, power down

Enter sleep: AEh, A5h (power save compound); exit: A4h, AFh (Figure 6, labelled "UC1503t" in the datasheet). A plain
AEh also enters sleep. Display off for a full screen update: AEh, write the RAM, AFh (RAM is kept in sleep).

Power down (p. 34, 35): E2h (reset mode activates the draining circuit), wait ~1 ms (Figure 9) or ~3 ms (sample
sequence), then switch off VDD. Before switching on again VDD must stay below 0.1 V for > 10 ms; fall time < 10 ms.

## 8 The vic head `src/head/ST7565.h`

The UC1701x is driven by `vic::head::ST7565<ST7565_UC1701, ...>`; template parameters, framebuffer layout,
`present()` and the display control functions are described in `ST7565.md` section 8. For `ST7565_UC1701` the init
sequence is `E2h (5 ms), A2h / A3h, A0h, C0h, 40h, F8h 00h, 2Ch, 2Eh, 2Fh (50 / 50 / 10 ms), 20h | ratio, 81h volume,
A6h, A4h, AFh`.

| Item | UC1701x datasheet | Head | Result |
|---|---|---|---|
| Command codes | section 4 | ST7565R codes | OK, all used codes exist with the same meaning |
| RAM layout, addressing | D0 = top, 132 columns, page 8 = CIC | page wise with `Column_Offset` | OK; wrap around is off by default, the head addresses every page |
| Reset | power on reset, E2h, RST optional; commands 5 .. 10 ms after VDD on, 6 ms after RST | E2h right after `io::init()`, then 5 ms | OK if the io layer / application respects the power on and RST delays |
| Booster ratio | F8h xx is a NOP | F8h 00h sent | harmless |
| Power control | no waits needed | 2Ch / 2Eh / 2Fh with 50 / 50 / 10 ms | works, 110 ms longer than necessary |
| VLCD with the defaults | ratio 110b (7.517), PM 32: 10.2 V; with 110b PM must stay <= 48 for 11.5 V | Resistor_Ratio 6, Contrast 20h | OK at init; `display_contrast()` from level 196 on (PM > 48) exceeds 11.5 V, PM 63 gives 12.6 V |
| Bias | BR 0 = 1/9 at 1/65 | A2h | OK |
| Display off | AEh = sleep mode, AFh restores the power | `display_enable(false)` = AEh | OK |
| Shutdown | E2h to drain the capacitors, then VDD off; sleep only for short periods | `shutdown()` = AEh (sleep) | the draining reset is missing for a power off |
| Temperature compensation | default -0.11 %/C (APC0 90h) | not changed | OK |
| Reads, status | dummy read, BZ | no reads | OK |
