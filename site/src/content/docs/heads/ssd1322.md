Head for the SSD1322 OLED controller (480 x 128 RAM, 16 gray levels), used on the common 256 x 64 modules (e.g.
NHD-3.12-25664). The RAM holds 4 bits per pixel, two pixels per byte. The head renders into a RAM framebuffer (8 KB for
256 x 64) and sends it with `present()`. The serial interfaces can't read back.

```cpp
#include "head/SSD1322.h"
```

## Template parameters

```cpp
template<std::uint16_t Screen_Size_X = 256U, std::uint16_t Screen_Size_Y = 64U,
         drv::orientation_type Orientation = drv::orientation_0,
         std::uint8_t Column_Offset = 0x1CU,
         std::uint8_t Contrast      = 0x9FU>
class SSD1322;
```

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `Screen_Size_X` | `std::uint16_t` | 256 | logical width, 256 for `orientation_0` / `180`, 64 for `90` / `270` |
| `Screen_Size_Y` | `std::uint16_t` | 64 | logical height |
| `Orientation` | `drv::orientation_type` | `orientation_0` | orientation, done in software |
| `Column_Offset` | `std::uint8_t` | 1Ch | first RAM column of the panel in units of 4 pixels (1Ch for the 256 pixel modules, panel in the middle of the 480 columns) |
| `Contrast` | `std::uint8_t` | 9Fh | contrast current 0..255 |

The physical width must be a multiple of 4 and the panel must fit into the 480 x 128 RAM (`static_assert`).

## Constructor

```cpp
SSD1322(io::handle_type device_handle);
```

| Parameter | Type | Meaning |
|---|---|---|
| `device_handle` | `io::handle_type` | logical device handle of the bus |

## Color format and interface

4 bit gray (`color::color_to_L4()`, the average of R, G and B), high nibble = left pixel.

| Call | Option | Meaning |
|---|---|---|
| `io::write()` | 0 | command byte (D/C# low) |
| `io::write()` | 1 | parameters and the frame data (D/C# high) |

The head never reads.

## Orientation

All eight orientations, mapped in software into the framebuffer. The remap register stays at `04h 11h` (nibble remap,
dual COM up to 64 rows, no mirror). The NHD modules are upright with `orientation_0m`.

## Native hooks and read back

`pixel_set()`, `pixel_get()`, `cls()` and `present()`, the other primitives use the `drv` fallbacks on the RAM buffer.
`pixel_get()` reads the framebuffer, so alpha blending and anti aliasing work with 16 gray levels. `present()` sends
the whole frame (8192 bytes for 256 x 64): collect a frame with `dc.present_lock()`.

## Head specific functions

| Function | Meaning |
|---|---|
| `framebuffer()` | pointer to the row organized framebuffer (physical orientation) |
| `display_enable(bool)` | AFh / AEh (sleep mode, RAM retained) |
| `display_contrast(level)` | contrast current C1h |
| `display_brightness(level)` | master contrast C7h, level / 16 (16 steps) |
| `display_inverse(bool)` | A7h / A6h (GS0 and GS15 exchanged) |

## Init sequence

The u8g2 / NHD-3.12 reference sequence: unlock (FDh 12h), display off, clock B3h 91h, MUX = rows - 1, offset and start
line 0, remap `04h 11h`, GPIO, internal VDD regulator (ABh 01h), enhancement A `A0h FDh` (external VSL), contrast,
master contrast 0Fh, linear gray table, phase length E2h, enhancement B, precharge voltages, VCOMH, normal display,
partial off, display on, then clear and present. `shutdown()` switches the display off.

## Example

From `demo/heads/SSD1322.cpp` (3.12" 256 x 64 module on 4 wire SPI):

```cpp
#include "head/SSD1322.h"
#include "scene.h"          // demo_scene(): frame, line, circle, disc and text

static vic::head::SSD1322<256, 64, vic::drv::orientation_0m> oled(reinterpret_cast<vic::io::handle_type>(0));

int main()
{
  oled.init();
  demo_scene(oled);
  // gray ramp along the bottom line
  vic::dc d(oled);
  for (std::int16_t x = 0; x < 256; ++x) {
    const std::uint8_t gs = static_cast<std::uint8_t>(x);
    d.plot({ x, 62 }, vic::color::argb(gs, gs, gs));
  }
  return 0;
}
```

## Controller notes

[SSD1322.md](https://github.com/mpaland/vic/blob/master/src/head/doc/SSD1322.md): up to 480 segments x 128 commons,
30 KB GDDRAM with 4 bits per pixel; 6800 / 8080 and 3 / 4 wire SPI (write only). The window is set with 15h (columns
in units of 4 pixels, 0..119) and 75h (rows), data follow 5Ch. Remap A0h: A[0] vertical increment, A[1] column remap,
A[2] nibble remap, A[4] COM scan remap, A[5] COM split, second byte dual COM. A column address is 4 pixels wide, so 90
degree rotations are not possible in hardware. Brightness through contrast current C1h and master contrast C7h,
gray scale table B8h or linear B9h. Enhancement A `A0h` selects the external VSL, the reference modules have the
external VSL network.
