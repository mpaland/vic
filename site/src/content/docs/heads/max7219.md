Head for the MAX7219 / MAX7221 LED driver driving an 8 x 8 LED matrix. The pixels are kept in a small RAM buffer
(one byte per row) because the chip can't be read back, `present()` writes the rows to the digit registers. Chains of
modules are combined with the [`multihead`](/vic/heads/multihead/).

```cpp
#include "head/MAX7219.h"
```

## Template parameters and constructor

```cpp
template<std::uint16_t Screen_Size_X = 8U, std::uint16_t Screen_Size_Y = 8U,
         drv::orientation_type Orientation = drv::orientation_0>
class MAX7219;

MAX7219(io::handle_type device_handle);
```

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `Screen_Size_X` | `std::uint16_t` | 8 | screen width, normally 8 |
| `Screen_Size_Y` | `std::uint16_t` | 8 | screen height, normally 8 |
| `Orientation` | `drv::orientation_type` | `orientation_0` | orientation of the matrix, done in software in `present()` |
| `device_handle` | `io::handle_type` | | logical SPI device handle |

## Color format and interface

1 bit per pixel: any color which is not black (`color::color_to_L1()`) switches the LED on. Every register write is
one `io::write()` with option 0 and two bytes (register, data), i.e. one 16 bit SPI frame latched with LOAD / CS.
SPI mode 0, MSB first, up to 10 MHz.

## Orientation

All eight orientations, the rows are rotated or mirrored in `present()`. The scan limit register is set from the
height (0 / 180 orientations) or the width (90 / 270).

## Native hooks and read back

Only `pixel_set()`, `pixel_get()`, `cls()` and `present()`; all other primitives use the `drv` fallbacks.
`pixel_get()` reads the RAM buffer, so alpha blending against the real pixels works (with 1 bit, a pixel is on or
off).

## Head specific functions

| Function | Meaning |
|---|---|
| `display_enable(bool)` | shutdown register: normal operation / shutdown mode |
| `display_brightness(level)` | intensity register, upper nibble of the level (16 steps) |

The register addresses (`REG_NOOP`, `REG_DIGIT0`, `REG_DECODE`, `REG_INTENSITY`, `REG_SCANLIMIT`, `REG_SHUTDOWN`,
`REG_TEST`) are public constants.

## Init sequence

`io::init()`, scan limit, no decode mode, normal operation, test mode off, clear, full brightness. `shutdown()` clears
the matrix and enters the shutdown mode.

## Example

From `demo/heads/MAX7219.cpp` (one 8 x 8 module):

```cpp
#include "head/MAX7219.h"
#include "scene.h"          // demo_scene(): frame, line, circle and disc

static vic::head::MAX7219<8, 8> matrix(reinterpret_cast<vic::io::handle_type>(0));

int main()
{
  matrix.init();
  demo_scene(matrix);
  matrix.display_brightness(64U);
  return 0;
}
```

`demo/heads/multihead.cpp` combines four modules to a 32 x 8 screen, see [multihead](/vic/heads/multihead/).

## Controller notes

There is no datasheet summary in `src/head/doc/` for the MAX7219. The head uses the digit registers 01h..08h for the
rows, decode mode 09h = 00h (no BCD decode), intensity 0Ah, scan limit 0Bh, shutdown 0Ch and display test 0Fh.
