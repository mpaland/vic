Head for the 132 x 64 monochrome COG LCD controllers ST7565, ST7567 and UC1701 (128 x 64 panels like EA DOGM128 or
ERC12864). The three controllers share the command set (page / column addressing, bit 0 = top row of a page). The head
renders into a RAM framebuffer and sends it page by page with `present()`. The serial interfaces can't read back.

```cpp
#include "head/ST7565.h"
```

## Template parameters

```cpp
template<ST7565_controller_type Controller = ST7565_ST7565,
         std::uint16_t Screen_Size_X = 128U, std::uint16_t Screen_Size_Y = 64U,
         drv::orientation_type Orientation = drv::orientation_0,
         std::uint8_t Column_Offset  = 0U,
         std::uint8_t Contrast       = 0x20U,
         std::uint8_t Resistor_Ratio = 0x06U,
         bool Bias_1_7 = false>
class ST7565;
```

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `Controller` | `ST7565_controller_type` | `ST7565_ST7565` | `ST7565_ST7565` (ST7565R/P), `ST7565_ST7567` (booster 4x / 5x only, 4x after reset), `ST7565_UC1701` (F8h is a NOP) |
| `Screen_Size_X` | `std::uint16_t` | 128 | logical width, 128 for `orientation_0` / `180`, 64 for `90` / `270` |
| `Screen_Size_Y` | `std::uint16_t` | 64 | logical height |
| `Orientation` | `drv::orientation_type` | `orientation_0` | orientation, done in software |
| `Column_Offset` | `std::uint8_t` | 0 | first RAM column of the panel (the RAM has 132 columns, some 128 pixel modules start at 4) |
| `Contrast` | `std::uint8_t` | 20h | electronic volume 0..63 |
| `Resistor_Ratio` | `std::uint8_t` | 6 | V0 regulator resistor ratio 0..7 |
| `Bias_1_7` | `bool` | false | true for 1/7 bias, false for 1/9 bias |

The physical height must be a multiple of 8 and offset + width must fit into 132 columns (`static_assert`).

## Color format and interface

1 bit per pixel, any color which is not black sets the pixel (`color::color_to_L1()`).

| Call | Option | Meaning |
|---|---|---|
| `io::write()` | 0 | command bytes (A0 low) |
| `io::write()` | 1 | display data (A0 high), one page per call |

SPI mode 0 or 3. The head never reads. `io::init()` has to pulse the reset line (/RES, RSTB): the ST7565R and ST7567
need a hardware reset after power on, the software reset E2h of `init()` doesn't replace it (the UC1701 has a power on
reset).

## Orientation

All eight orientations, mapped in software into the framebuffer; the SEG and COM direction commands stay at their
defaults (A0h, C0h). The DOGM128 / ERC12864 modules are upright with `orientation_180` or `orientation_0m`.

## Native hooks and read back

`pixel_set()`, `pixel_get()`, `cls()` and `present()`, all other primitives use the `drv` fallbacks on the RAM buffer.
`pixel_get()` reads the framebuffer. `present()` sends all pages: collect a frame with `dc.present_lock()`.

## Head specific functions

| Function | Meaning |
|---|---|
| `framebuffer()` | pointer to the page organized framebuffer (physical orientation) |
| `display_enable(bool)` | AFh / AEh, the RAM is retained |
| `display_contrast(level)` | electronic volume 81h, level / 4 |
| `display_inverse(bool)` | A7h / A6h |

## Init sequence

The power up sequence of the Adafruit ST7565 / u8g2 drivers: software reset E2h (5 ms), bias A2h / A3h, SEG normal A0h,
COM normal C0h, start line 40h, booster ratio F8h 00h (not on the ST7567), power control 2Ch, 2Eh, 2Fh with 50 / 50 /
10 ms, resistor ratio 20h + ratio, electronic volume 81h, normal display A6h, all points off A4h, display on AFh, then
clear and present. `present()` sends for every page `B0h + page`, the column address with the offset and the page
bytes. `shutdown()` switches the display off.

## Example

From `demo/heads/ST7565.cpp` (128 x 64 COG module, EA DOGM128 style):

```cpp
#include "head/ST7565.h"
#include "scene.h"          // demo_scene(): frame, line, circle, disc and text

static vic::head::ST7565<vic::head::ST7565_ST7565, 128, 64, vic::drv::orientation_180> lcd(reinterpret_cast<vic::io::handle_type>(0));
// variants:
//   vic::head::ST7565<vic::head::ST7565_ST7567, 128, 64>                                lcd_st7567;
//   vic::head::ST7565<vic::head::ST7565_UC1701, 128, 64, vic::drv::orientation_0, 4U>   lcd_uc1701;   // column offset 4

int main()
{
  lcd.init();
  demo_scene(lcd);
  lcd.display_contrast(0x90U);
  return 0;
}
```

## Controller notes

[ST7565.md](https://github.com/mpaland/vic/blob/master/src/head/doc/ST7565.md): up to 132 segments x 65 commons, RAM in
9 pages (page 8 is the icon row). 8 bit 6800 / 8080 or write only 4-line SPI. Commands: display on / off AEh / AFh, start
line 40h, page B0h, column 10h / 00h (high / low nibble), ADC A0h / A1h, normal / inverse A6h / A7h, all points A4h /
A5h, bias A2h / A3h, reset E2h, COM direction C0h / C8h, power control 28h (booster, regulator, follower), resistor ratio
20h, electronic volume 81h, booster ratio F8h. Two mirror bits only, with A1h a 128 column panel starts at RAM column 4.

[ST7567.md](https://github.com/mpaland/vic/blob/master/src/head/doc/ST7567.md): same command set with an on-chip 4x / 5x
booster, 4x after reset (so the head skips F8h). The hardware reset RSTB is essential, E2h doesn't reset display, MX,
bias, booster and power control. The power off sequence of the datasheet (AEh, A5h, 250 ms) is not done by `shutdown()`.

[UC1701.md](https://github.com/mpaland/vic/blob/master/src/head/doc/UC1701.md): ST7565R compatible codes, internal
charge pump, power on reset (RST optional); F8h is accepted as a NOP. With the default resistor ratio,
`display_contrast()` levels from about 196 on exceed the 11.5 V VLCD limit. For a power off the datasheet drains the
capacitors with E2h, the head's `shutdown()` only enters sleep (AEh).
