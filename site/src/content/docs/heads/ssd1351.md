Head for the SSD1351 RGB OLED controller (128 x 128, 65k colors). The head writes directly into the GDDRAM (no
framebuffer): pixels are streamed through the column / row address window with native auto increment, the
orientation is done with the remap bits. Unlike the SSD1331 the controller has no graphic accelerator.

```cpp
#include "head/SSD1351.h"
```

## Template parameters

```cpp
template<std::uint16_t Screen_Size_X = 128U, std::uint16_t Screen_Size_Y = 128U,
         drv::orientation_type Orientation = drv::orientation_0,
         bool RGB_to_BGR = true>
class SSD1351;
```

| Parameter | Type | Default | Meaning |
|---|---|---|---|
| `Screen_Size_X` | `std::uint16_t` | 128 | logical width (128 x 128, or 128 x 96 / 96 x 128 for the 1.27" panels) |
| `Screen_Size_Y` | `std::uint16_t` | 128 | logical height, must match the orientation |
| `Orientation` | `drv::orientation_type` | `orientation_0` | hardware orientation (remap bits) |
| `RGB_to_BGR` | `bool` | true | swap the color order (remap bit A[2]), the common modules need it with RGB565 data |

The panel must fit into the 128 x 128 RAM (`static_assert`).

## Constructor

```cpp
SSD1351(io::handle_type device_handle);
```

| Parameter | Type | Meaning |
|---|---|---|
| `device_handle` | `io::handle_type` | logical device handle of the bus |

## Color format and interface

RGB565 big endian (65k format, `color::color_to_RGB565()`).

| Call | Option | Meaning |
|---|---|---|
| `io::write()` | 0 | command byte (D/C# low) |
| `io::write()` | 1 | parameters and pixel data (D/C# high), pixels in blocks of 32 |
| `io::read()` | 1 | two pixel bytes after the read RAM command 5Dh (parallel bus only) |

SPI mode 0, 20 MHz in the demo.

## Orientation

All eight orientations with the remap register A0h: vertical address increment for the rotated orientations,
column remap = X mirror, COM scan remap = Y mirror; 65k format and COM split are always set. `orientation_0` is the
datasheet default, the common 1.5" modules are upright with `orientation_0m` (Adafruit remap 74h).

## Native hooks and read back

| Hook | Implementation |
|---|---|
| `pixel_set()` | sets the window only if the tracked write pointer is not already at the pixel |
| `line_horz()` | one window and a pixel stream |
| `line_vert()` | a one column wide window |
| `box()` | window over the clipped rect and a pixel stream |
| `blit()` | window over the clipped block, the pixels are streamed |
| `cls()` | one stream over the whole screen |
| `move()` | `drv` fallback, needs read back |

`pixel_get()` sets a one pixel window and reads it with 5Dh. The GDDRAM can only be read on the parallel bus; on SPI
the I/O layer returns `false` and `pixel_get()` returns `color::none`, see
[Write only displays](/vic/design/write-only-displays/).

## Head specific functions

| Function | Meaning |
|---|---|
| `display_enable(bool)` | AFh / AEh |
| `display_brightness(level)` | master contrast C7h, level / 16 |
| `display_contrast(level)` | scales the three channel contrasts (C8h / 80h / C8h), the color balance is kept |
| `display_inverse(bool)` | A7h / A6h |

## Init sequence

The Adafruit_SSD1351 values: unlock (FDh 12h, FDh B1h), display off, clock F1h, MUX = rows - 1, remap from the
orientation, start line and offset 0, GPIO, internal VDD regulator, phase period, VCOMH, normal display, contrasts,
master contrast, external VSL, second precharge, display on, then clear. `shutdown()` switches the display off.

:::note
Not covered: 262k color formats, scrolling, the gray scale table and the start line offset of the 128 x 96 panels.
:::

## Example

From `demo/heads/SSD1351.cpp` (1.5" SPI module):

```cpp
#include "head/SSD1351.h"
#include "scene.h"          // demo_scene(): frame, line, circle, disc and text

static vic::head::SSD1351<128, 128, vic::drv::orientation_0m> oled(reinterpret_cast<vic::io::handle_type>(0));

int main()
{
  oled.init();
  demo_scene(oled);
  oled.display_contrast(200U);
  return 0;
}
```

## Controller notes

[SSD1351.md](https://github.com/mpaland/vic/blob/master/src/head/doc/SSD1351.md): 128 RGB x 128, 18 bit GDDRAM with 65k
(16 bit) or 262k (18 bit) formats, 8 / 16 / 18 bit 6800 / 8080 and 3 / 4 wire SPI (write only). Window 15h / 75h,
write RAM 5Ch, read RAM 5Dh. Remap A0h: A[0] vertical increment, A[1] column remap, A[2] color swap, A[4] COM scan
remap, A[5] COM split, A[7:6] color depth. Contrast per color C1h, master contrast C7h, gray table B8h / linear B9h.
After reset several commands (A2h, B1h, B3h, BBh, BEh, C1h) are locked until `FDh B1h`; the display offset resets
to 60h, which is why the head writes A2h 00h.
